# SnapQR

A simple and customizable QR code generator that allows users to generate QR codes from their content with ease.

**Live Demo:** [https://snapqr-eqeo.onrender.com](https://snapqr-eqeo.onrender.com)

## Features

- Generate QR codes from user-provided content.
- Customize QR code colors.
- Simple and clean user interface.
- Responsive design.
- Download generated QR codes.

## Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Java
- Spring Boot
- Maven

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/SnapQR.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SnapQR
   ```

3. Open `index.html` in your browser or run the project using a local development server.
